## 🚀 Giới thiệu

Project này là một ứng dụng mobile được xây dựng bằng  **React Native**

---

## 🛠️ Công nghệ sử dụng

* React Native
* TypeScript
* Zustand
* Axios / Fetch API
* React Navigation

---

## 📂 Cấu trúc thư mục

```
src/
│── assets/        # images, fonts
│── components/    # reusable components
│── screens/       # màn hình chính
│── navigation/    # config navigation
│── services/      # gọi API
│── store/         # state management
│── hooks/         # custom hooks
│── utils/         # helper functions
│── constants/     # biến constant
```

---

## ⚙️ Cài đặt

### 1. Clone project

```bash
git clone https://github.com/iamkvnn/cinx-native
cd cinx-native
```

### 2. Cài dependencies

```bash
npm install
```

### 3. Chạy project

#### Android

```bash
npx react-native run-android
```

#### iOS

```bash
cd ios && pod install && cd ..
npx react-native run-ios
```
